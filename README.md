When users experience severe anxiety or panic attacks, generic AI chatbots fail them. They either hallucinate dangerous medical advice or trigger safety filters that completely refuse to help, leaving the user isolated.

UnPanic is a local-first, privacy-preserving Psychological First Aid Agent powered by Gemma 4. It acts as an emotional shock absorber, utilizing an advanced RAG (Retrieval-Augmented Generation) architecture to deliver grounded, evidence-based coping mechanisms (CBT, DBT, Somatic therapies) without ever attempting to diagnose.
